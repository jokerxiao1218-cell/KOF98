# 拳皇98 复刻(KOF98 Remake · Pygame)

单角色 1v1 格斗:特瑞·伯格(Terry Bogard)对入门 AI(蓝马甲换色版)。
320×224 内部画布 ×3 放大到 960×672,60fps,Pygame 程序绘制素材(可选真贴图,见下)。

> 项目事实来源是 [拳皇98复刻-设计文档.md](拳皇98复刻-设计文档.md)(需求卡/契约/测试计划/batch 进度/遗留清单全在里面),接续开发先读它。本 README 只做上手指引。

## 快速开始

```bash
./run.sh     # 开打(标题画面按任意键)
./test.sh    # 全量 pytest(无头,不需显示器)
```

venv 自带全部依赖(pygame 2.6.1 / pytest),不联网。本机如有 ROS 等 PYTHONPATH 污染,脚本已自动 `unset`。

## 操作(键盘)

| 键 | 作用 | | 键 | 作用 |
|---|---|---|---|---|
| A / D | 左 / 右 | | **U** | 轻拳(A) |
| W | 跳(含小跳:轻点) | | **I** | 轻脚(B) |
| S | 蹲 | | **O** | 重拳(C) |
| D·D 双击 | 前冲 | | **P** | 重脚(D) |
| 拉住后方 | 防御(站/蹲自动) | | F1 | 调试框(红=攻击判定 黄=受击 绿=推挤) |
| ESC | 暂停 | | 关窗/失焦 | 自动暂停 |

**出招表**(数字=小键盘方位:2↓ 4← 6→ 3↘ 1↙):

| 招式 | 指令 | 备注 |
|---|---|---|
| 能量波 Power Wave | ↓↘→ + U/O | 飞行道具 |
| 燃烧拳 Burn Knuckle | ↓↙← + U/O | 前冲拳 |
| 爆裂踢 Crack Shoot | ↓↙← + I/P | 弧线踢 |
| Power Dunk | →↓↘ + I/P | 升空砸拳 |
| 升龙撞 Rising Tackle | **按住 ↓ 约 0.7 秒** → ↑ + U/O | 蓄力技 |
| 能量喷泉 Power Geyser | ↓↘→↓↘→ + U/O | **超杀,需能量槽满** |
| 前投 / 后投 | 近身 →或← + O | 投技不可防御 |

能量槽打人/挨打都会涨;满槽(100)出超杀。三局两胜,双 KO 各记一局,满血胜出判 PERFECT。

## 仓库结构

```
game/
  core/            战斗核心(与渲染无关,可无头跑)
    fighter.py     角色状态机+物理(走/跑/跳/蹲/防/投/受击/倒地/起身)
    motion.py      输入合成(搓招/蓄力/双击前冲识别)
    combat.py      攻防结算(命中/防御/互拼/连段缩放)
    match.py       对局管线(回合/KO/计时/摄像机/每方独立 hitstop)
    ai.py          种子确定的对战 AI
    data.py        三份 JSON 加载+全量校验(坏数据当场炸)
    types.py       全部契约 dataclass(键名冻结)
  art/             纸娃娃素材:terry_base(部件库)+ 四家族姿势表 + 门面
  assets.py        素材出口(sprite:程序绘制/真贴图单一接入点)
  sprites.py       真贴图注册表(manifest 切格/锚点/P2 换色/无图回退)
  poses.py         姿势键名与帧数注册表
  ui.py            场景栈/HUD/键盘/出招 timing 对齐(打击帧=判定帧)
data/              角色招式/系统/AI 三份 JSON(数值全在这,调参不改代码)
tests/             245 个 pytest(无头,像素采样代替肉眼看图)
scripts/           demo(自对弈确定性)/截图/自检/贴图体检/ASCII 过目
```

## 素材:程序绘制 与 真贴图

默认全部姿势由**程序纸娃娃**绘制(部件字符画+摆放表,零图片文件),P1/P2 换色只换调色板。
想用真 sprite sheet:把自己下载的 PNG 和 manifest 放进 `game/sprites/terry/`(目录整体
gitignore,**版权图永不入库**),跑 `env -u PYTHONPATH .venv/bin/python scripts/sprite_check.py`
体检,过了自动启用;目录空/坏配置则自动整包回退程序绘制。模板见
`scripts/manifest.example.json`。

## 开发纪律(为什么这个仓库长这样)

- **设计文档是唯一事实来源**:数值改动先写进文档再动 JSON;测试是需求的定义,不许为了让测试变绿而改考卷。
- **测试无头跑**:像素采样断言代替肉眼;任何 PNG 一律不进 AI 会话(用 `scripts/ascii_pose.py` 看姿势)。
- **确定性**:同种子自对弈逐字节一致(demo 双跑断言);AI、随机性全部受种子控制。
- 想了解设计取舍/已知遗留,读设计文档 §10(诚实清单)。
